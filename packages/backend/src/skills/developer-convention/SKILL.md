# Конвенция разработчика (D-16)

Норматив — в `packages/backend/.idea/ARCHITECTURE.md` §6. Этот скил объясняет, *зачем* каждое правило, чтобы его не выкинули в занятую неделю. Держит конвенцию `ai-adapter-completeness.spec.ts`: красный тест, не ревью.

Любой новый модуль, сервис или фича обязан прибыть комплектом:

- `<module>-ai.adapter.ts` рядом с доменом — иначе агент скажет тенанту, что такой сущности нет, хотя UI уже умеет её открыть.
- `src/skills/<module>/SKILL.md` — иначе модель получает capability без наших конвенций и начинает их выдумывать.
- строка в `module-coverage.registry.ts` — иначе новый каталог в `src/modules/` сам красит сборку, и обойти это можно только сознательной классификацией.

Не добавлять инструменты в `McpToolsService`. После cutover 15-15 tools существуют только если их объявил адаптер.

## Контракт обработчика

- `vpbxUserUid` — параметр вызова handler. Никогда не замыкание при регистрации и никогда не свойство `inputSchema`. Иначе модель сможет подставить чужой тенант, как в старом MCP-реестре.
- Мутирующие tools возвращают proposal (`proposes: true`), а не пишут в АТС напрямую. Запись без карточки нельзя отменить и нельзя показать человеку.

## Формат скила

Frontmatter — ровно два однострочных поля, без вложенности и списков. Парсер ручной, библиотеки YAML нет; вложенность молча отвалится из каталога, и модель просто не узнает, что скил существует — пока completeness-тест не назовёт файл.

    ---
    name: <id>
    description: <one line>
    ---

Тела скилов не кладутся в системный промпт: туда идёт только каталог имён и однострочных описаний. Тело читается через `read_skill`.

Несколько доменов могут честно делить один скил (`sharedSkill` в классификации): речевые движки, операционные каталоги, каналы сообщений. Stub на каждый каталог хуже исключения — он учит модель нулю, притворяясь покрытием.

## Если модуль не должен быть покрыт

Не пропускать каталог. Записать его как `infrastructure` или `excluded` с непустой причиной в `module-coverage.registry.ts`. Причина — то, что отличает решение от недоделки: без неё исключение неотличимо от забытого адаптера, и правило выключат.
