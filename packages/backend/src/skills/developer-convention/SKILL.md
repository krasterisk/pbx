# Конвенция разработчика (D-16)

Любой новый модуль, сервис или фича обязан прибыть парой:

- `<module>-ai.adapter.ts` рядом с доменом
- `src/skills/<module>/SKILL.md`

Спека полноты (D-16/D-17) красит отсутствующую пару красным. Модуль без адаптера или без скила считается недоделанным.

## Контракт обработчика

- `vpbxUserUid` — параметр вызова handler. Никогда не замыкание при регистрации и никогда не свойство `inputSchema`.
- Мутирующие tools возвращают proposal, а не пишут в АТС напрямую.

## Формат скила

Frontmatter — ровно два однострочных поля, без вложенности и списков:

    ---
    name: <id>
    description: <one line>
    ---

Тела скилов не кладутся в системный промпт: туда идёт только каталог имён и однострочных описаний. Тело читается через `read_skill`.
