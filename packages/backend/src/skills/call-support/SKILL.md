# Проблема со звонком

1. Зафиксируй вызывающий/вызываемый номер, организацию текущей сессии, время с часовым поясом и симптом. Не делай широкий экспорт CDR.
2. Для своего внутреннего номера вызови get_endpoint_registration. Для DID — describe_number. При неверном расписании используй evaluate_time_group на время инцидента.
3. Найди конкретный звонок find_cdr_calls/get_recent_call_events; для текущего звонка get_live_channels. Изучай get_compiled_dialplan только собственного контекста.
4. Разделяй наблюдения и гипотезы. Отсутствие CDR, offline и hangup cause не определяют единственную причину. При усечении сузь окно.
5. Нет звука: проверь факт ответа, направление отсутствующего аудио, NAT/кодеки/транспорт. Доступные инструменты не доказывают прохождение RTP: запроси разрешённый диагностический захват у оператора, не утверждай наличие packet loss без метрик.
6. Не перезапускай общий Asterisk, не включай глобальный SIP debug и не меняй firewall. Предложи минимальное изменение своей сущности через карточку, затем повтори исходный сценарий.
7. Эскалация: время, tenant, собственный endpoint/uniqueid, инструменты и факты, гипотезы, недостающие данные. Пароли, Authorization и чужие звонки исключены.
