# Голосовые меню

Меню — карта цифр. Каждая цифра (`1`–`9`, `0`, `*`, `#`) ведёт звонящего в одно назначение. Смена цифры меняет маршрутизацию входящих, даже если старый флаг называл это «безопасной» правкой.

## Рецепт

1. **Что прочитать.** `read_skill` для `ivrs`, `endpoints` и `call-groups`, если в запросе есть абоненты или группа на таймаут. Затем `list_endpoints` по названным номерам (например `101-103`). Не утверждай «абонентов нет» по sample снимка `get_pbx_state`.
2. **Чеклист из слов пользователя.** Бери факты из **любой** реплики треда, не только из последней. Короткое «да, создай IVR» не отменяет исходный текст и карту цифр. Только то, что назвали: абоненты → одна группа на таймаут → меню. Не три группы и не 702/703/704, если пользователь назвал 101–103.
3. **Одна карточка.** Если не хватает абонентов, группы или меню — это **один** `propose_plan` на весь заказ, не серия `create_*` и не три подтверждения. Номер группы на таймаут бери сам из свободных 6xxx. Движок — Yandex или первый из `list_tts_engines`. Не спрашивай то, что уже названо.
4. **Вопрос без карточки.** Спрашивать можно только факт, которого нет ни в одной реплике и который нельзя выбрать самому (например неизвестный внешний номер). Имя, текст приветствия, цифры и члены группы не переспрашивай.

Исполняемый чеклист для «IVR Продажи, 1→101, 2→102, 3→103, таймаут → группа 101–103»:

1. `list_endpoints` с фильтром `101-103`. Отсутствующие номера — шаг `create_endpoints_bulk` внутри `propose_plan`, не отдельная карточка.
2. `list_call_groups`. Одна группа с членами 101–103 — шаг `create_call_group` в том же плане. Свободный `exten` 6xxx подставь сам.
3. `list_tts_engines`. Перед нетривиальной цепочкой — `list_dialplan_apps(host=ivr)`. Затем шаг `create_ivr` в том же плане: текст приветствия (`text` или `prompts`), цифра `t` → `{ kind: group, target: номер группы }`, цифра → абонент — `kind: extension`.
4. Вызови `propose_plan` один раз и остановись. Не пиши резюме карточки в чат.

Цифра → абонент — это `extension` → действие `toexten` с публичным номером (`101`, не `e101_0` и не `dial`). Не отдельная группа на каждую цифру. Текст приветствия не клади в `description` — у меню такого поля нет.

## Допустимые назначения

Цифра — не одно поле «куда», а **цепочка действий** того же редактора, что у маршрутов (`DialplanAppsEditor`, host `ivr`). Сокращение `destination: {kind, target}` задаёт только **первый** шаг.

Виды первого шага:

- `context` — контекст (`toroute`)
- `extension` — внутренний абонент (`toexten`)
- `queue` — очередь (`toqueue`)
- `menu` — другое меню (`toivr`)
- `group` — группа вызова (`togroup`). Таймаут (`t`) / «ничего не нажали» обычно начинается с группы.

Дальше в `actions[]` только типы из `list_dialplan_apps(host=ivr)`: `totrunk` (внешний номер через транк из `list_trunks`), `voicemail`, `playback`, `text2speech`, `hangup`, `tolist`, `goto`, `schedule`. Не выдумывай приложения Asterisk. Не предлагай менять настройки группы, чтобы сделать overflow — у группы его нет. Не подменяй группу очередью только ради внешнего номера.

Пример «t: звонят все в группе, иначе городской»:  
`{"digit":"t","actions":[{"type":"togroup","params":{"target":{"source":"fixed","value":"9010"}}},{"type":"totrunk","params":{"trunk":"<имя из list_trunks>","dest":{"source":"fixed","value":"<номер>"}}},{"type":"hangup","params":{}}]}`

Назначение, которого нет у тенанта, отвергается до подтверждения: в отказе названы цифра и отсутствующая цель. Не оставляй цифру пустой — звонящий услышит тишину. Не мапь группу на `extension`.

## Таймаут и неверный ввод

- `t` — таймаут (абонент ничего не нажал)
- `i` — неверный ввод

Это договорённость меню, не отдельные сущности. Обе цифры — обычные пункты с цепочкой. Если после группы ничего не поставить, вызов просто закончится. Нужен внешний номер, почта или сброс — добавь шаг в эту цепочку, не спрашивай «группа или очередь».

## Откуда звонящий попадает в меню

Меню почти всегда достигается со **входящего маршрута** (`toivr`). Перед правкой прочитай маршруты тенанта: какая линия и какой шаблон ведут сюда. Не предлагай менять меню, не зная, кто в него входит.

Не подставляй чужой `vpbxUserUid`. Не применяй смену цифры без карточки before/after.
