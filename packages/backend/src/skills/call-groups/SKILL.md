# Группы вызова

Группа в этом продукте — фиксированный список, которому звонят сразу. Ищется по `uid` внутри тенанта вызова. Номер (`exten`) — 2–8 цифр и должен быть свободен среди групп, очередей и внутренних абонентов этого тенанта.

## Рецепт

1. **Что прочитать.** `list_call_groups` и `list_endpoints` для названных членов. Снимок не доказывает, что группы нет.
2. **Чеклист из слов пользователя.** Бери факты из **любой** реплики треда, не только из последней. «Группа 101-103» или «таймаут на 101–103» — это **одна** группа с тремя членами, не три группы. Не выдумывай 702/703/704.
3. **Висит карточка.** Не пересказывай её в чат. Если в том же запросе ещё меню или абоненты — это один `propose_plan`, не отдельная карточка группы. Сначала абоненты в том же плане, если членов ещё нет.
4. **Когда остановиться.** Спрашивать можно только то, чего нет ни в одной реплике треда: свободный `exten` группы. Уже названных членов и имя не переспрашивай. Не выдумывай номер (9002 / 702). Полный ТЗ не закрывай меню «что настроить».

Члены должны уже существовать; если их ещё нет — сначала карточка абонентов, затем попроси подтвердить и только после этого создавай группу.

## Стратегии

Продукт отдаёт четыре стратегии группы, не стратегии очереди:

- `ringall` — звонят все члены сразу
- `hunt` — по списку сверху вниз, каждый раз сначала
- `memoryhunt` — по списку с памятью, следующий после того, кто ответил в прошлый раз
- `random` — случайный порядок

Не подставляй `leastrecent` / `rrmemory` — это стратегии очереди. Смена состава или стратегии — живые звонки, только через proposal.

## Группа и очередь

У **карточки группы нет overflow** и нет поля «после таймаута набрать внешний». `ring_time` — только сколько секунд звонят члены. Если никто не взял, управление возвращается в **вызывающую цепочку**: пункт IVR или маршрут (тот же редактор действий, что у маршрутов).

Не предлагай «очередь вместо группы», чтобы дозвониться на городской или сбросить вызов. Это следующие шаги цепочки после `togroup`: `totrunk` (транк + номер), `voicemail`, `hangup`, `playback`. Типы и поля — в `list_dialplan_apps(host=ivr|route)`. Очередь — когда звонящий должен ждать в линии, слушать музыку и уходить в overflow-контекст очереди.

## Членство

Член `internal` — extension абонента этого тенанта. Несуществующий номер отвергается до карточки с этим номером. `external` — внешний номер через `external_context` группы.

`update_call_group_members` заменяет состав целиком. В карточке пиши **кого добавляем и кого убираем**, не итоговый список: «members: 101, 102, 105» скрывает, что 103 сняли.

Удаление группы в карточке называет маршруты и меню, которые на неё звонят.
