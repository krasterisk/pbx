# Контексты

Контекст — именованный контейнер маршрутов одного тенанта. Это не общий диалплан Asterisk и не теория телефонии: агент выбирает контекст, в который кладёт маршрут.

## Именование и uid

`list_contexts` возвращает `uid`, `name`, `comment`. Для `create_route` нужен `uid` из этого списка, не угаданное имя. В Asterisk к имени добавляется суффикс тенанта; агент не конструирует это имя сам и не подставляет чужой `uid`.

## Тенант

Список всегда принадлежит тенанту вызова. Аргумент модели с чужим `vpbxUserUid` или `tenantId` не меняет выборку. Контекст тенанта A не бывает в ответе тенанта B.

## Связь с маршрутами

Маршрут живёт в одном контексте. Сначала `list_contexts`, затем создание или правка маршрута в выбранном `uid`. Применять диалплан — шаг подтверждения изменения (не отдельный вызов `apply_dialplan` из этого домена).
