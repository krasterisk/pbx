# Обзор АТС
Используй get_pbx_dashboard для сводки звонков, доступности и ресурсов в контексте текущего пользователя.
Проверяй state и updatedAt каждого источника. Ноль, неизвестно и устаревшие данные различаются.
Один звонок может содержать несколько каналов. Ответ IVR/голосовой почты не является ответом сотрудника/AI.
Инструмент только читает данные; не выполняет AMI опрос и не меняет настройки.
