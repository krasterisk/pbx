<objective>
Довести АРМ оператора до 4-зонной концепции (UI-SPEC §1) и закрыть решения D-18…D-21:
1. **Pick call с per-user разрешением (D-18)** — перехват звонка из своих очередей выполняется, только если у оператора включено `pickup_enabled` в `cc_operator_settings` (сущность из 07-05). Проверка обязательна на **сервере** (403 при выключенном), UI дополнительно скрывает кнопку.

4. **DnD-перевод с модалкой на 3 действия (D-21)** — расширить существующий `DragTransfer` с одной кнопки Transfer до «Слепой перевод / С консультацией / Отмена».
