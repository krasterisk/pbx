# Phase 7 — UI Design Contract

> Visual and interaction contract for the Call Center overhaul (agent workspace, supervisor workspace, wallboard, call cards, reports, chat, softphone, settings). Generated by gsd-ui-researcher, verified by gsd-ui-checker.

**Sources:** 07-CONTEXT.md (D-01…D-45), `packages/frontend/.idea/ARCHITECTURE.md` (locked stack + FSD rules), sketch-findings-krasterisk-v4 skill (validated dark/indigo direction), `.idea/call-center/CC_WORKSPACES_CONCEPT.md`, `.idea/call-center/CC_CALL_CARD_CONCEPT.md`, `.docs/CALLCENTER_MODULE.md`, existing `globals.css` `@theme` tokens and `CallCenterAgentPage.module.scss` status patterns.

## Design System

| Property | Value |
|----------|-------|
| Tool | none (manual shadcn-style; `components.json` absent by design — do NOT run `shadcn init`) |
| Preset | not applicable |
| Component library | Radix primitives + CVA, wrapped in `@/shared/ui` (Dialog, Select, DropdownMenu, Tooltip, etc.) |
| Icon library | `lucide-react` ONLY (emoji icons strictly forbidden) |
| Font | Inter (already global via `--font-sans`) |
| Styling | Tailwind ONLY inside `shared/ui`; SCSS modules with `var(--color-*)` / `var(--radius-*)` / `var(--z-index-*)` in `entities/features/widgets/pages` |
| Tables | TanStack Table via existing `shared/ui/DataTable` |
| Charts | Recharts, wrapped in `shared/ui` wrappers (FSD rule: third-party components must be wrapped) |
| Animation | Motion (Framer) for state transitions; CSS transitions for hover/color |
| Theme | Dark-first (`#09090b`); light theme must remain functional (tokens flip via `.light`) |
| i18n | ru (primary) + en via `useTranslation()`; all new keys added to BOTH `shared/config/locales/ru.ts` and `en.ts` |

**Token source of truth:** `src/app/styles/globals.css` `@theme`. No new hex values may be introduced in SCSS modules; transparency only via `color-mix(in srgb, var(--color-X) N%, transparent)`.

## Spacing Scale

Declared values (multiples of 4, existing 8-point scale confirmed):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, badge padding, chip internals |
| sm | 8px | Compact element spacing, gaps inside KPI cards, table cell padding-y |
| md | 16px | Default element spacing, card padding, form field gaps |
| lg | 24px | Section padding, gaps between workspace zones |
| xl | 32px | Layout gaps between page header and content |
| 2xl | 48px | Wallboard section breaks |
| 3xl | 64px | Wallboard page-level margins (TV viewing) |

**Exceptions (documented, allowed):**
- **44×44px minimum touch/click target** for call control buttons (Answer, Hangup, Hold, Mute, Transfer, DTMF keys) — operators click these under time pressure.
- **12px** internal gap in the dense supervisor KPI strip and dense table rows (existing `DataTable` convention).
- **2px** active-tab underline (architecture tabs pattern) and 1px borders — structural, not spacing.

---

## Typography

Exactly 4 sizes, 2 weights. Line heights: body 1.5, headings/numerics 1.2.

| Role | Size | Weight | Line Height | Usage |
|------|------|--------|-------------|-------|
| Body | 14px | 400 | 1.5 | Tables, forms, chat messages, list rows, labels (labels use 600) |
| Section title | 16px | 600 | 1.2 | Card headers, modal section headings, tab labels use 14px/600 |
| Heading / KPI | 20px | 600 | 1.2 | Page H1 (gradient, per sketch direction), KPI values in supervisor strip, active-call caller name |
| Display | 28px | 600 | 1.2 | Active-call timer, agent detail modal header |

**Rules:**
- All numeric timers, counters, and KPI values use `font-variant-numeric: tabular-nums` (prevents jitter on live updates).
- Muted secondary text = 14px/400 with `var(--color-muted-foreground)`; never a 5th font size.
- **Wallboard exception (locked):** the wallboard is a TV surface viewed from 3-5 m. Its KPI numbers use `clamp(48px, 6vw, 96px)` weight 600, section labels `clamp(16px, 1.5vw, 24px)`. This exception applies ONLY inside `CallCenterWallboardPage` and is out of the 4-size budget.
- Page H1 pattern (agent/supervisor/reports/settings): gradient title + 14px muted subtitle, per sketch-findings winner A.

## Color

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `var(--color-background)` #09090b | Page background, workspace canvas |
| Secondary (30%) | `var(--color-card)` #0a0a0f + `var(--color-sidebar)` #121218 + `var(--color-muted)` #18181b | Zone cards, KPI cards, table shells, modals, chat panel |
| Accent (10%) | `var(--color-primary)` #6366f1 (indigo) | See reserved list below |
| Destructive | `var(--color-destructive)` #ef4444 | Destructive actions + critical alert states only |

**Accent (`--color-primary`) reserved for:**
- Primary CTA button on each surface (one per view)
- Active tab underline (2px) and active sidebar nav item
- Focus rings (`--color-ring`)
- Grid↔Table toggle active segment
- Sparkline stroke and live chart primary series
- Selected DnD drop target highlight (`color-mix` 12% background + 1px primary border)
- Unread chat badge and links

**Semantic status palette (locked; already established in `CallCenterAgentPage.module.scss` — do not remap):**

| State | Token | Applies to |
|-------|-------|-----------|
| Ready / answered / SLA ok | `--color-success` #22c55e | Agent status dot+chip, answered counters, SLA ≥ target |
| Paused / warning threshold | `--color-warning` #f59e0b | Pause status, SLA approaching threshold, wait 30-60s |
| In Call / critical / lost | `--color-destructive` #ef4444 | In-call status, abandoned calls, SLA < threshold, wait > 60s, Hangup button |
| Wrap-up / informational | `--color-info` #3b82f6 | Wrap-up status, info banners, callback-done badge |
| Offline / inactive | `--color-muted-foreground` #71717a | Offline agents, disabled rows |

Status chips always render as: `color-mix(token 12%, transparent)` background + token text + `color-mix(token 25%, transparent)` border + 8px status dot (pattern already in code — reuse).

**Alert thresholds visualization (D-27):** value text switches token (success → warning → destructive) at configured thresholds; on wallboard a critical KPI additionally gets a 2s pulse animation of its card border (`color-mix(destructive 40%)`). No other blinking anywhere in the product.

**Chart palette (Recharts):** primary series `--color-primary`; comparative/secondary series `--color-info`; positive/negative fills `--color-success` / `--color-destructive` at 20% via color-mix. Heatmap: 5-step ramp from `color-mix(primary 8%)` to `--color-primary`.

## Screen & Interaction Contracts

### 1. `/callcenter/agent` — Operator workspace (4 zones, D-18…D-22)

- **Layout:** Zone A status bar sticky top (height 56px); Zone B active call center; Zone D quick actions right sidebar 320px collapsible; Zone C queue monitor bottom, collapsible. Desktop grid `1fr 320px`; tablet: Zone D becomes overlay Sheet; mobile (<768px): only Zones A+B stacked, C/D behind toggles.
- **Status transitions** (READY/RINGING/IN_CALL/WRAPUP/PAUSED/OFFLINE) animate via Motion: chip crossfade + dot color transition 150ms. Ringing state pulses the status dot (success token), 1s cycle.
- **Active call card:** caller name 20px/600, number + queue 14px muted, timer 28px tabular-nums. Controls row: Hold, Mute, Transfer, DTMF, Hangup — 44px targets, Hangup uses destructive variant and sits last, separated by 16px.
- **Wrap-up block:** countdown progress bar (info token), «+30 сек» extend button (secondary), «Готов к следующему» primary. On timeout: draft card autosaves, toast «Черновик карточки сохранён», state → READY (D-19).
- **DnD transfer (D-21):** drag active call card onto a contact in Zone D; drop target shows primary highlight; drop opens confirmation modal with exactly three actions: «Слепой перевод» (primary), «С консультацией» (secondary), «Отмена» (ghost). Click on contact = same modal (no instant blind transfer).
- **Pick call (D-18):** `[Перехватить]` ghost-primary button per waiting-call row; hidden entirely (not disabled) when per-user permission is off.
- **Wait-time coloring in queue monitor:** <30s foreground, 30-60s warning, >60s destructive.
- **Sounds/notifications (D-20):** incoming ring, missed-call chime, zip tone before auto-answer (D-16); Browser Notification when tab inactive («Входящий звонок: {number}, очередь {queue}»); per-operator volume/off in settings.

### 2. `/callcenter/supervisor` — Supervisor workspace (D-23…D-25)

- **KPI strip:** 7 metric cards in a horizontally scrollable row; each card = label 14px muted, value 20px/600 tabular-nums, 40×16px sparkline (primary stroke), threshold-colored value. Max-wait card value switches to destructive and pulses text (no blink) above threshold.
- **Tabs:** Операторы / Очереди / Звонки — architecture tabs pattern (single 1px container border + 2px primary underline, -1px overlap).
- **Grid↔Table toggle (D-24):** segmented 2-button control (LayoutGrid / Table2 lucide icons), active segment primary; persisted in `localStorage` key `cc:supervisor:view`.
- **Agent card (grid):** status chip, name 16px/600, live timer, calls today, current queue chips; actions row of icon buttons (Pause/Unpause, Spy, Whisper, Barge, Queues, Logout) with tooltips.
- **Agent detail modal:** `DialogContent size="xl"`; header = agent + status chip; body = today stats grid + reusable `AgentTimeline` component (live mode) (D-36).
- **Queue management modal:** two lists (in queue / available) with DnD between them (`@dnd-kit`, same pattern as IvrPromptsEditor); penalty inline-editable number; remove requires confirm.
- **Bulk actions:** row checkboxes in table view; selection bar slides up from bottom (Motion) with «Пауза», «Снять с паузы», «Разлогинить» + count; Разлогинить is destructive-styled and confirms.
- **Live calls actions:** Pickup / Transfer / Hangup icon buttons per row; Hangup destructive + confirm modal.

### 3. `/callcenter/wallboard` — TV surface (D-26…D-29)

- Fixed layout, no navigation chrome, no interactive controls except fullscreen button (auto-hides after 3s idle). Route works with display token (no login) — render nothing tenant-identifying beyond CC data.
- Sections top→bottom: KPI row (4-6 giant numbers), calls/hour live chart (current hour highlighted with primary), agents strip (status dots grid + counts per status), queues list (name, SLA progress bar, wait/talk counts).
- Dark background mandatory even if user theme is light. Spacing: 48/64px. All numbers tabular-nums.
- Threshold breach: card border pulse (destructive) + optional sound if enabled in thresholds settings.

### 4. Call Cards (builder + popup, D-10…D-13)

- **Builder (`/callcenter/settings` tab):** two-pane layout — left: field palette + field config; right: live preview rendering the actual `CallCardPopup` renderer (single source of truth, no separate preview markup). DnD reorder via `@dnd-kit`; field rows show drag handle (GripVertical), label, type badge, width toggle (full/half), required indicator.
- **Popup (`CallCardPopup`):** right-side Sheet (new `shared/ui/Sheet`, 480px, over Zone D) — NOT a centered Dialog, so call controls stay visible. Header: caller id + queue (readonly). Fields render per template: `full` = 1 column, `half` = 2-column grid collapsing to 1 below 640px. Wrap-up countdown visible inside the sheet footer when active.
- Auto-open per template: `answer` / `ring` / `never` (D-12). VIP match from phonebook: warning-token left border 3px + star icon.
- Dependent fields animate in/out with 150ms height transition.

### 5. `/callcenter/reports` (D-33…D-36)

- Page pattern: header (gradient H1 + subtitle) → filter bar card (period, queue, agent selects; sticky) → report content card. 7 reports switch via architecture-pattern tabs or left list on ≥1280px.
- Tables: `DataTable` (client-side); heatmap: CSS grid with 5-step primary ramp + tooltip values; `AgentTimeline`: horizontal 24h track with colored segments per state (status palette above), zoomable brush, shared with supervisor detail modal.
- Export bar: «Экспорт CSV», «Экспорт XLSX», «Экспорт PDF» — secondary buttons, right-aligned above table.

### 6. Internal chat (D-30…D-32)

- Right-side collapsible panel (320px) available in agent and supervisor workspaces; opened via header icon with unread badge (primary).
- Conversation list (personal / groups / broadcast) → thread view. Own messages: `color-mix(primary 12%)` bubble right-aligned; others: `--color-muted` left-aligned; broadcast messages: info-token left border + Megaphone icon. Timestamps 14px muted.

### 7. Softphone (D-14…D-17)

- **Shift login modal:** mode RadioCards «SIP-устройство» / «Браузер (WebRTC)» + extension select + (browser mode) mic/speaker device selects with live mic level bar.
- **In-call quality indicator:** 4-bar icon in Zone A; success ≥ good, warning = degraded, destructive = poor; tooltip shows MOS/jitter/RTT.
- **DTMF keypad:** 3×4 grid in Popover, 44px keys, keyboard input mirrored.

### 8. `/callcenter/settings` (D-40) and navigation (D-37…D-39)

- Single page, architecture tabs: Шаблоны карточек / Причины пауз / Пороги алертов / Настройки операторов / Display-токены.
- Display tokens tab: table of tokens with created/last-used, «Создать ссылку» primary CTA, copy-URL button, revoke (destructive + confirm).
- Sidebar: «Колл-центр» group; operator (level 2) sees only АРМ оператора; supervisor (3+) sees agent/supervisor/wallboard/reports; admin adds settings. Old `/operator`, `/supervisor` redirect.

### Cross-cutting states

| State | Contract |
|-------|----------|
| SSE disconnected | Non-blocking banner top of workspace, warning token: «Соединение потеряно. Переподключение...»; auto-hides on reconnect; data area dims to 60% opacity |
| Loading | `Skeleton` blocks matching final layout (no spinners on full pages); button-level `Loader` for mutations |
| Empty | Icon (lucide, muted, 32px) + heading 16px/600 + body 14px muted + optional CTA (see copywriting) |
| Error (query) | Inline card with destructive-tinted border, problem + retry button «Повторить» |
| Motion budget | 150ms color/opacity, 200ms layout (Motion), wallboard pulse 2s; `prefers-reduced-motion` disables pulses and slide-ins |

## Accessibility & Responsive (contract-level)

- All interactive elements keyboard-reachable; DnD flows (transfer, builder, queue management) MUST have click/menu equivalents.
- Status is never conveyed by color alone: chips always pair dot + text label.
- Focus visible via `--color-ring`; modals trap focus (Radix default).
- Breakpoints per architecture: 360px min → 2560px; grid layouts collapse at 640px; supervisor grid 2 columns at 768-1280px; wallboard targets 1920×1080 primarily.
- Tables in modals/cards wrapped in `overflow-x-auto`.
