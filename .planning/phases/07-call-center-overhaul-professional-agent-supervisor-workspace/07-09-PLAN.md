## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser client → backend CC API | React-клиент под контролем пользователя; уровень роли (`auth.user.level`), видимость кнопок и маршрут — всё client-side и подделываемо. Авторизация должна решаться на сервере. |
| supervisor action → Asterisk (AMI Originate/Redirect/Hangup/QueuePenalty) | Действия супервизора управляют реальными каналами Asterisk; неавторизованный/кросс-тенантный вызов = вмешательство в чужие звонки. |
| uniqueid/agentInterface (вход запроса) → tenant (vpbx_user_uid) | Идентификаторы звонка/агента приходят из клиента; сервер обязан подтвердить принадлежность тенанту перед действием. |
