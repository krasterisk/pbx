Wave 4 — отчётность колл-центра v1 + экспорт (D-33/D-34/D-36). Строится поверх фундамента 07-01 (`cc_queue_calls`), движка метрик 07-03 (формулы SLA/ASR/AHT/ASA/Occupancy/Abandon, `DEFAULT_SLA_THRESHOLD_SEC`) и rollup/гибридной агрегации 07-04 (`CallCenterRollupService.resolveAggregationSource`, `cc_daily_*`).

Реализуется:
1. **7 отчётов** (backend, tenant-scoped): сводка очередей, детализация звонков, статистика операторов, отчёт по паузам, почасовая heatmap, agent timeline, пропущенные (с отметкой перезвона). Агрегируемые отчёты (queue-summary, operator-stats) выбирают источник через `resolveAggregationSource` (raw ≤90д / rollup >90д); построчные/почасовые/паузные/timeline/missed отчёты читают сырьё напрямую (rollup их не хранит).
2. **Переиспользование Agent Timeline** (D-36): единый пресентационный компонент `AgentTimeline` СОЗДАЁТСЯ в 07-09 (его владелец) и здесь только ИМПОРТИРУЕТСЯ/переиспользуется для отчёта agent-timeline. 07-12 НЕ создаёт собственный timeline-компонент. Backend `getAgentTimeline` этого плана готовит `segments` (сегменты состояний из `cc_agent_events`) в той же форме `AgentTimelineSegment`, что и `getAgentDetail` 07-09 — компонент принимает готовые сегменты пропсом. Отсюда зависимость `07-12 → 07-09` (Wave 4).
3. **Экспорт CSV/XLSX/PDF** (D-34): CSV — reuse hand-rolled builder (образец `reports/cdr/cdr.controller.ts`, delimiter `;` + BOM + esc); XLSX — новый `exceljs` (streaming `writeBuffer`); PDF — на клиенте через уже установленный `@react-pdf/renderer` из уже загруженных строк отчёта (тяжёлая агрегация остаётся на backend, PDF рендерит только отображаемые агрегаты — утечки сырья нет).

Purpose: отчётность — ключевая корпоративная фича КЦ; `AgentTimeline` — один переиспользуемый компонент (владелец 07-09), чтобы supervisor agent-detail modal и отчёты не дублировали логику; экспорт в 3 формата — прямое требование D-34.
Output: backend reports service + controller + 2 exporter'а, клиентская страница `/callcenter/reports`, переиспользование `AgentTimeline` (из 07-09), клиентский PDF-генератор.
