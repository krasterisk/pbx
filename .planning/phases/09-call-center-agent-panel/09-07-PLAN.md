## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| client → call-control endpoints | untrusted uniqueid/target/queue input |
| backend → AMI (Hangup/Park/ConfBridge/Originate) | privileged, potentially destructive actions on live channels |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-09-07-01 | Denial of Service | zombie-reset griefing | mitigate | resetZombieCall enforces call belongs to the requesting operator's own active call (D-27); supervisor variants scoped to assigned queues |
| T-09-07-02 | Elevation of Privilege | cross-tenant park/conference/hangup | mitigate | Every method opens with getCall → call.userUid===userUid tenant guard before AMI |
| T-09-07-03 | Elevation of Privilege | click-to-call without permission | mitigate | clickToCall gated by PermissionsService.click_to_call (server-side) |
| T-09-07-04 | Tampering | raw client AMI | mitigate | No AMI action reachable from client; all go through guarded service methods |
| T-09-07-05 | Denial of Service | ConfBridge/Park resource abuse | accept | Bounded by existing tenant/queue scope + JWT auth; monitored, low blast radius for MVP |
</threat_model>
