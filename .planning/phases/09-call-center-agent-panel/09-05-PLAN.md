| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-09-05-01 | Elevation of Privilege | peerSpy cross-tenant/cross-queue | mitigate | Shared-online-queue + targetAgent.userUid===userUid checks before AMI; supervisor scope limited to assigned queues (D-25) |
| T-09-05-02 | Repudiation | ChanSpy listen (silent) | mitigate | Mandatory audit-log row (who/whom/mode/time) via LoggerService.logAction before originate (D-24) |
| T-09-05-03 | Elevation of Privilege | self-editable locked right | mitigate | PermissionsService enforces lock on getEffective; override ignored when locked (server-side, not UI-only) |
| T-09-05-04 | Tampering | client-sent permission flag | mitigate | Effective rights always resolved server-side from DB; client flags never trusted |
| T-09-05-05 | Information Disclosure | spy on non-spyable agent | mitigate | target.spyable required; requester can_spy + mode∈spy_modes required |
