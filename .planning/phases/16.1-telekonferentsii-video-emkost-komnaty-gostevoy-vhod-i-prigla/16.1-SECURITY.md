### T-16.1-06 — open (blocking)

Ожидалось: stamp + `ConfbridgeKick` + destroy **безусловно** в одном `revoke()`; `join` **не** минтит triple, если `revoked_at` / `expires_at` уже сработали.

Факт (аудитор + L1):

1. `join()` (`conference-guest.service.ts:110-141`) — `findByPk` затем сразу `createEphemeralGuestEndpoint`. Нет re-check `revoked_at` / `expires_at`. Guard — единственный gate. TOCTOU: revoke между `canActivate` и create всё равно выдаёт `{ sipId, password }` в `krsk-conf-{uid}`.
2. `revoke()` (`conference-guest.service.ts:170-190`) — stamp всегда; Kick только если `findLiveParticipant(... )?.channel && amiService`. После restart / до Join / `CallerIDNum ≠ sip_id` Kick пропускается; destroy PJSIP не выкидывает уже bridged канал.
3. Нет теста «create только если не revoked». Есть только happy-path Kick при живом snapshot.

**Residual:** отозванный гость может получить новые SIP creds и/или остаться в ConfBridge с медиа до hangup.
