<objective>
Turn every agent mutation into a draft that a human accepts, and make acceptance the only path to a write — including the five directory write tools that already exist (D-15).

Purpose: D-18 and D-19 replace agreement-by-text and agreement-by-model-flag with a confirmation card the user clicks. D-20 makes the database write and the dialplan reload one confirmed step, because a state where the database says one thing and the switch does another is worse than either. D-21 keeps the agent inside the caller's existing permissions. The correct orchestrator for a route change is the one the interface button already uses — the legacy tool that applies dialplan inline skips directory binding policies and duplicates context naming, so the agent currently applies routes worse than the interface does; this plan makes the good path the only path. 15-01 Task 2 left a destructive blanket refusal in `callTool` until this plan replaces it; without that replacement, `delete_directory` and `remove_directory_records` stay refused, and the three unmarked directory writes keep writing immediately.

Output: `PbxAgentDiffService`, authenticated apply and reject endpoints, `callTool` persist path for `proposes` tools, directory mutations as proposals, validated proposal transport objects, and a precedence safety check.
</objective>
