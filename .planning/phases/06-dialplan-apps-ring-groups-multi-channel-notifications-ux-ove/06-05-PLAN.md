<feature>
  <name>Call group dialplan generator (4 strategies, Gosub/Return)</name>
  <files>packages/backend/src/modules/call-groups/call-group-dialplan.util.ts, packages/backend/src/modules/call-groups/call-group-dialplan.util.spec.ts</files>
  <behavior>
    - `ringall`: `exten => start,1,NoOp(...)` then one `Dial(<member1>&<member2>&...,<ring_time>,tT)` then `Return()`
    - `hunt`: per member in order, `Dial(<member>,<member.ring_time>,tT)` each followed by `ExecIf($["${DIALSTATUS}" = "ANSWER"]?Return())`, final `Return()`
    - `memoryhunt`: growing sets (1, 1+2, 1+2+3...), each `Dial` followed by ANSWER-Return check, final `Return()`
    - `random`: `Set(GRP_PICK=${RAND(1,N)})` + GotoIf table (random first member then remaining in order); each branch ends `Return()` (v1 simplification per RESEARCH A1 — document as such)
    - internal member → `PJSIP/e<value>_<vpbx>`; external member → `LOCAL/<value>@<group.external_context>`
    - the category name equals `group_<group.uid>_<vpbx>`
    - generated `lines` never include the substring `Hangup`; last line is `Return()`
    - optional `cid_prefix`: when set, `Set(CALLERID(name)=<prefix> ${CALLERID(name)})` emitted before Dial (D-09 optional; document if implemented)
    - all member values + prefix pass through `AsteriskDialplanUtils.sanitizeDialplanInput`
  </behavior>
