## Decisions Made
- End is confirm-then-leave: backend has no dedicated `/end` route; hangup still goes through `useConferenceRoom.leave`
- UA is gated on staff join CTA plus SIP password/domain/WSS so `noWebrtcCompanion` never starts sip.js
- `created_by` vs JWT `uniqueid` drives `adminJoinNotice` once; owner role is inferred the same way
- Weak link = `qualityLimitationReason` `cpu` or `bandwidth`; 409 on GET room toasts `live.full`
- Header shows room name + short number only — never a tenant conference name
