## Реализация 2026-10-17

Сделано: строка отчёта — человек; время смены только из журнала (готов + занят + паузы = смена); фильтр очереди не смешивает звонки и смену и скрывает «звонков в час»; RNA, занятость, использование, доля пауз, короткие, переводы, исходящие; зона видимости супервизора в отчёте, экспорте и секции операторов дашборда; рассылки по местным суткам тенанта; медиана, подсветка по целям, сравнение с прошлым периодом, наборы колонок, переходы в смену / паузы / пропуски; цели в настройках; миграция `0047` (таблицы и индексы).

Отклонения:

- Отчёт читает сгруппированный SQL по `cc_queue_calls` на любой длине периода, а не новые дневные таблицы. Старая сводка не хранит очередь и журнал. Таблицы `0047` созданы для следующего переключения.
- Полный сценарий L1 на трёх WebRTC-софтфонах не запускался. Живая проверка: API на реальной смене стенда (баланс журнала) и один отвеченный звонок через Asterisk (1 обработан, 4 с разговора, AHT 4).
- Команды, интервальный график, FCR, оценка качества и цели на человека не делались: для них нет команд, графика смен и связи речевой аналитики со звонком.
