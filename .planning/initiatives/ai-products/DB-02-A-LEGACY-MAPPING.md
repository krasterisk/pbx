2026-09-18. Сверено с [42 найденными regex-поиском entry points](evidence/db-01/legacy-cli-inventory.txt), четырьмя действующими `ai-chat/migrate-agent-*` из npm scripts и текущими 112 AppModule models / обеими canonical 0001 baselines: **46 entry points**. Эти скрипты **не входят** в versioned manifest и не запускаются при чистой установке. Для существующей непомеченной истории действует DB-01 refusal + ручная инвентаризация/adoption; запуск всех старых скриптов подряд не является upgrade path.

Исторические SQL лежат в `packages/backend/migrations/mysql` и `packages/backend/migrations/postgres`; они **не** входят в canonical `packages/backend/database/migrations/manifest.json`. `packages/backend/database/migrations/postgres/0001-current-schema.sql` — новый canonical static artifact; прочие исторические SQL требуют отдельного per-artifact review. PostgreSQL baseline намеренно создаёт только структуру AppModule models и PostgreSQL equivalents; `queue_log`/CEL и ODBC mapping — DB-03.

**Не покрытые clean-install guarantees:** historical скрипты местами добавляют FK/индексы, отсутствующие в Sequelize models (например, `fk_cgm_call_group`, `fk_cc_card_fields_template`, conference meeting FK), и выполняют backfill/удаление старых столбцов. Эти действия не перенесены без проверки данных и не разрешены для автоматического upgrade. Для DB-02-A достаточен эквивалент текущих моделей на пустой БД; полный upgrade существующей неверсированной установки и Asterisk writer schema остаются отдельными gates.
