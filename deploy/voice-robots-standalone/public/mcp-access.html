Адрес сервера
  1. Создайте ключ с нужными правами.
  2. В настройках клиента выберите Streamable HTTP и укажите этот адрес.
  3. Добавьте ключ в приватный заголовок Authorization: Bearer <ключ>.

Ключ действует только для роботов текущего кабинета.
