# AI-01-A2 — signed BOX license and independent activation

Status: implemented backend slice, 2026-09-18. Assignment: `AI-01-A2-license` in [EXECUTION](EXECUTION.md), PLAN `AI-01-A-ACCESS-PLAN.md` A2 at SHA-256 `C46E8834643A706635CF97FCBE69930E11D45CF97739F6930CF6258E5D1984E1`.

The two AI products now use one persisted access adapter. CLOUD reads tenant-scoped explicit or documented legacy entitlement and a separate activation. BOX verifies a signed Ed25519 license bound to installation and tenant, then checks activation; OpenSource remains closed for commercial packages. The existing module guard and `/marketplace/ai-products/*/access` projection reach this adapter through `ModulesRegistryService`. Scenario robots and other legacy module policies were not migrated.

An installation superadmin may import a fully verified BOX license for an explicit tenant at `POST /cloud-admin/ai-products/licenses/tenants/:userUid/import`. A tenant admin may set `PUT /marketplace/ai-products/:code/activation`; OFF leaves entitlement and configuration intact. The import is transactional, keeps signed document history, rejects revision downgrade/conflict, requires `replace=true` for a different license ID, and audits actor, digest and product codes without logging signed payload. Tenant UID `0` is handled as a valid number. The verifier checks exact canonical bytes, trusted local public keys, issuer/installation/tenant/product, validity window, and no grace. Every BOX admission rechecks the signature and persisted maximum observed time to detect local clock rollback. This is local detection, not a guarantee against full snapshot restoration.

Additive migration `0004-ai-product-access.sql` and its PostgreSQL counterpart create the activation, document and binding tables. Both use the same manifest ID. No migration grants a product or automatically activates it. The [license wire contract](AI-01-A2-LICENSE-CONTRACT.md) documents issuance requirements and the fixed test vector.

The product catalog remains unpublished and direct purchase stays blocked while runtime, tariffs and commercial approval are incomplete. No signing private key, demo license, cloud wallet dependency or remote license lookup was added. An independent security review and business approval remain mandatory before issuing real licenses or publishing the commercial offer. Next assigned slice should be A3 provider readiness; A2 does not implement AI robot or analytics processing.
