# DB-02-D3 — сценарные голосовые роботы: CDR tags

Статус: реализован для существующих сценарных роботов. Будущие AI-роботы остаются отдельной сущностью.

Последний элемент массива `voice_robot_cdr.tags` теперь извлекается ограниченным SQL-адаптером для MySQL/PostgreSQL. `NULL`, пустой массив и последний JSON `null` не дают тега; строка `"null"` остаётся обычным тегом. Точные значения фильтра передаются Sequelize как данные, tenant scope остаётся в каждом запросе. Список тегов использует parameterized tenant ID и одинаковую сортировку. Подстрочный поиск воспринимает `%`, `_` и `\` как буквальные символы. При равном `started_at` порядок CDR дополнительно закреплён по `uid`.

Весь сценарный runtime, ARI и будущие LLM-агенты этим срезом не менялись.
