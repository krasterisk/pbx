## Сделано в срезе

- Секрет тикетов fail-closed, каталог шага `robot_uid`, диалплан ставит `AI_ROBOT_OUTCOME` и не молчит при пустом роботе, ветки `GotoIf` по исходам.
- Контракт v2 (`toRobotConfigV2` / `fromRobotConfigV2`), шаблоны, миграция `0048` в оба диалекта и профили.
- Сохранение пишет `config_json`, хранит 50 версий, rollback. Текстовый движок с инструментами и egress-guard. Playground API и панель теста в редакторе.
- База знаний принимает текст и ищет по чанкам; URL в документе больше не считается вредоносным содержимым.
- ARI подписывается на `krasterisk_ai_voice`; слушатель отвечает, ставит исход и возвращает канал в маршрут.
- R4.2: ARI-listener читает tenant из канала, если `StasisStart` не передал dialplan variables, и fail-closed завершает шаг при отсутствующем владельце; есть unit-тесты на dedicated app, наследуемый tenant и отсутствие tenant.
- Адаптер aiChat `list_ai_robots` / `describe_ai_robot` и скил. Запись через `/ai-agents` закрыта (410), страница ведёт в студию.
- В сессии скриптового робота: hangup при сбое старта, лимит буфера STT, ожидаемое воспроизведение, SSRC на звонок, без двойного `sound:`, webhook через egress-guard.
