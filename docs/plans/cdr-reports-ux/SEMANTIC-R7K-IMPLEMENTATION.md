# CDR v1.2 — R7K: UX и инструменты aiChat

Текущий coordinator `/root/chat01a14cff-e054-7ba0-931d-95fd94bfb3e8`, mode `codex-direct`. Единственный план: PLAN.md v1.2 §12.19, продолжение R7K/K-AI. Это результат среза, не новый roadmap и не объявление выпуска всего v1.2.

## Реализовано

- Панель фильтров раскрывается/скрывается на desktop/mobile; дополнительные условия имеют явное состояние. Условия действуют при скрытой панели и показаны снимаемыми признаками.
- Именованные персональные выборки сохраняются в текущем браузере, отдельно для пользователя/компании. Относительные периоды восстанавливаются в актуальных датах часового пояса организации. Курсоры, открытая карточка и произвольные URL-параметры не сохраняются.
- Добавлен KPI исходящих, симметричный входящим; сервер считает всю выборку. Улучшены визуальные уровни, высота KPI, адаптивность и календарные иконки обеих тем.
- Новые оценки SA различают assessed/not_applicable/insufficient_evidence. Намеренный null не заполняется вторым запросом. Новая assessed-оценка без подтверждённой исходной цитаты становится insufficient_evidence. Это проверка буквального доказательства, не универсальная гарантия правильной интерпретации модели.
- Новый фактический DeepSeek-разбор контрольного разговора: приветствие75, возражения N/A, CSAT insufficient; карточка показывает статусы и доказательства.
- aiChat получил resolve_call_employees, summarize_employee_calls, search_call_content, get_call_analysis и summarize_call_conversations. Шесть прежних инструментов/алиасов сохранены.
- Имя разрешается по доступной истории, с учётом порядка слов/однофамильцев. «Мои звонки» определяется по текущему пользователю. Инициатор исходящего отличается от участника переведённого звонка. totalConnectedSec — точная сумма известных интервалов всего логического звонка, не среднее×число и не личное время сотрудника.
- «Вчера»/«прошлая неделя» вычисляет сервер в зоне организации. Тематический поиск использует существующий CDR semantic service и права SA; возвращает контакт и ссылку на реплику, без сырого snippet.
- Read-mode и128-tool budget основного aiChat сохраняют точные CDR read tools; общие search/resolve mutations не разрешены. Три исходные формулировки пользователя распознаются как reports.
- Сводки различают cohort/considered/available/includedAnalyses. Ответ ограничен до3800 символов с явным contentTruncated, чтобы штатный4000-char лимит чата не разрезал JSON. Source quote/rationale остаются в карточке.

Общая модель роботов и существующий механизм embeddings не менялись. Production не обновлялся.

## Что остаётся до общей готовности

1. Полная проверка финальных ответов основного aiChat после исправлений; новое разрешение требуется только при повторной отправке реальных контактов в облако. Текущая разовая авторизация закрыта.
2. Независимая разметка и расширенный корпус, оставшиеся записи через полный цикл на финальном коде; явная стратегия переразбора старых защищённых результатов без новых bindings. Сохранённые H-разборы не выдаются за новые STT-запуски.
3. Доставка и приёмка полного приложения на целевой среде. Локальные/изолированные проверки не означают released.

Обязательных межчатовых согласований нет. Технический срез принят в описанных границах; собственные SQL/API/Vite и CI roots K/KA/KB очищены. Следующее действие — перечисленные gates расширенного корпуса, финальных ответов и целевой приёмки; общий milestone не объявлен завершённым.
