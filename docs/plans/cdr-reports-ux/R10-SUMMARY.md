2026-10-22. Координатор /root, codex-direct, единственный исполнитель. PLAN R10 revision1 с уточнением групп. Baseline main b03e97cf + сохранённые R8/R9 изменения. Чужие изменения support и остальные инициативы не редактировались. Публикации и коммита нет.

## Изменения

- Добавляемые условия вместо раскрытия всей формы: номера клиентов, сотрудник, отдел, номер компании, очередь, группа вызова, робот, транк, обработка и наличие материалов. Поиск значений внутри селектов; удаление нескольких условий одной URL-операцией; восстановление полей из сохранённой выборки. Сохранение доступно при раскрытых фильтрах.
- Группы определяются по собственному CDR/CEL context `group_<номер>_<tenant>`, с tenant-bound названием из справочника. Они входят в существующую индексируемую проекцию call_dimensions, фильтры, сохранённые выборки, экспорт и контракт AI-инструментов. Членство сотрудника в группе не используется как доказательство маршрута. CALL_FACTS_VERSION4, без изменения схемы БД.
- Некорректные URL-периоды пропускаются query hooks; ошибка выделена цветом и позволяет исправить даты. Время конца по умолчанию23:59, выбранная последняя минута включается полностью. Обзор/перезвоны ограничивают свою выборку366/31дн и показывают пояснение; исходный журнал сохраняет свой диапазон.
- Живой поиск: минимум3 символа,650мс после ввода, ожидание текущего запроса, trim, максимум200 символов, кнопка очистки и доступные состояния. Backend также отклоняет короткий поиск до построения SQL; существующий общий throttler сохранён. Поиск справочников ограничен128 символами, закрытие селекта сбрасывает удалённый поиск.
- При загрузке показываются индикатор и скелетон. Экспорт журнала: CSV и настоящий потоковый XLSX, общий фильтр и набор колонок, безопасные текстовые ячейки, состояние подготовки файла. Перезвоны и PDF также показывают состояние экспорта.
- Кнопка воспроизведения зависит от доступного безопасного файла, а не только от имени MixMonitor в CDR. Проверка после ACL, пакетно для страницы; соединение snapshot освобождается до проверки файлов/конфигурации.
- `POST /phone-session/restore`: отсутствие, истёкшая или чужая сессия возвращает штатный null. Heartbeat действующей сессии сохраняет строгую проверку владельца и409 при реальной потере сессии.

## Расшифровки и403

В текущей организации0 нет sa_projects и sa_analysis_runs; также отсутствует строка cloud tenants. Разрешение страницы зависит от доступного продукта, права на конкретный текст проверяются отдельно в проекте. Право ADMIN не заменяет entitlement или project transcript grant. Отсутствующий project grant возвращает unavailable без утечки текста; недоступная страница/продукт запрещены до чтения источника. Права и продуктовая активация не менялись.

Исправлен запрос из карточки по принудительному transcriptSegment при analytics=null. Полный клиентский путь «кнопка строки → Материалы → видимый текст» проверен с настоящими компонентами и синтетическим ответом API. Backend regressions проверяют администратора с разрешённым доступом, tenant/node/project/retention/audit и отказы. Это не новая положительная проверка реального текста в основном браузере: для неё здесь нет готового результата. Предыдущая R7 SQL/browser приёмка остаётся отдельным историческим доказательством. Не включались новая обработка, STT/LLM или выдача разрешений ради теста.
