## Реализация текущего назначения

- D1: reuse bounded DashboardCacheService внутри CallsService; RR checkpoint read и cache key включают tenant/user/permissionVersion/period/timezone/predicate/revision/source freshness. TTL5s, bounded LRU/singleflight, без stale-on-error. Смена прав и выборки не использует чужой cache.
- D2: employee/department/companyNumber participation, current/previous totals и исходы whole-call, unassigned rows, top50+explicit truncation. Не рейтинг ответа сотрудников; один звонок может участвовать в нескольких строках, суммы неаддитивны. Нормализованные call_dimensions — источник разрезов и фокуса переходов. focusEmployee/focusDepartment/focusCompanyNumber/focusOutcome пересекаются с исходной выборкой. unassignedDimensions поддерживает AND нескольких отсутствующих групп. Чипы/URL/экспорт сохраняют эти условия.
- D3: пропуски/голосовые, probable normalized full phone+company-number matching, completed non-autodial calls, window24h default, episodes of repeats, attempt separated from outbound connection/customer returned, unknown for missing identity/context/history. Ограниченные права не дают утверждать отсутствие реакции компании; положительное доказательство сохраняется. Source range<=31days, max10000 source/candidate rows, partial candidates do not become false overdue. Open/all view, source/attempt/contact links. Телефонное соединение не доказывает business resolution.
- Tenant policy: reports.calls.contact_window_hours в существующей tenant_settings, через собственный CDR endpoint GET/PUTpolicy, admin/superadmin only write,1..168h, default24. Generic allowlist не расширяется. RR read policy вместе с фактами; serializable write + atomic ActionLog, legacy table без уникального tenant/key. Изменение применяется к исторической выборке и объяснено UI. Новых migrations не добавлено.
- E1: search_calls/get_call/summarize_calls/list_unreturned_missed, aliases find_cdr_calls/get_cdr_summary теперь unified model. Actor загружается из users с tenant binding, актуальные права/license/participant scope проверяет CallsService; непривилегированный ctx.role не заменяет DB role. DTO validation и limit20/max50, безопасные ссылки, rawCEL/ASR не выдаются, analytics при отсутствии grant недоступна, search/aggregate/attention audit. Registered MCP discovery/isolation integration fixture обновлён только для reports.
- shared/lib/callsQueryParams — единый serializer URL/API; новые UI CallBreakdowns/CallAttention/CallContactPolicy, own calls locales/SCSS, без shared shell/robot/SA runtime writes.
