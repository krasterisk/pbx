## Реализовано

- D2: company calendar helper с точными полуоткрытыми интервалами. Реальные часы сохраняют обе DST occurrences, пропущенный час не становится искусственным интервалом. Поддержаны переход30min, зона+05:45, неполные ISO границы, пропущенная дата и день с началом01:00. callsPeriod теперь находит первый реальный момент календарной даты, не требует существования00:00.
- Агрегация переносима без timezone tables СУБД: compressed UTC-offset ranges + один grouped SQL в том же RR/tenant/participant/filter snapshot. Никакого SQL по каждому часу, выгрузки всего архива или подсчёта по ногам. Короткий timeline — реальные часы; свыше3суток — локальные дни, до367civil rows при допустимом elapsed диапазоне. Предыдущее сравнение по-прежнему равной фактической длительности и явно подписано.
- Тепловая карта с числами и интенсивностью, по7дней, отдельные ссылки повторного часа сUTC-offset, day/hour drilldown. Внутренняя горизонтальная прокрутка, фокусируемый region и стандартные ссылки/кнопки; обе темы. Отсутствующий слот честно подписан «вне выборки или отсутствует», а не выдан за нулевую нагрузку.
- E2 bounded: обновлён shipped product skill packages/backend/src/skills/reports/SKILL.md, шесть существующих инструментов/алиасы, tenant policy, coverage/unknown, неаддитивность участия, calendar offsets, запрет выдуманных цитат и semantic claims. Устаревшее ANSWERED=успех/ASR убрано. Cross-contract regression в reports-ai.adapter.spec.ts. Общий ai-chat/evals/runtime не менялся; настоящая RU LLM evaluation не выполнена.
- E3 structured: «Обсудить выборку с ИИ» в журнале/обзоре/внимании через существующий public aiChatActions.openWithSeed (новый чат). Page-level integration соблюдает разделение features. CallsPage возвращает фактический server period; seed фиксирует его, безопасные фильтры, timezone/observedTotal/revision/source и ссылку. Не передаёт rows/recordings/transcripts/auth/tenant argument/cursor/limit; неизвестные query поля отбрасываются. Нельзя открыть по старой выборке в процессе refetch/error/unavailable или без server period. AI обязан перечитать инструменты и сообщить смену ревизии; immutable snapshot не обещается. Для длинного архива выбирается search, для внимания<=31days — attention tool. Реальный ответ LLM/полный shell не проверялся.
