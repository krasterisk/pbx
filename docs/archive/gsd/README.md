# История GSD

Сохранённые фазовые планы, исследования, sketches/spikes findings и Markdown-итоги прежней разработки. Это историческая документация, не текущий backlog и не разрешение запускать команды из неё.

[Текущие назначения](../../plans/EXECUTION-REGISTRY.md), [канонический индекс](../../CANONICAL_REFS.md).

При миграции обновлены навигационные ссылки. Исходные bytes каждого документа сохранены во внешнем журнале миграции; SHA и исторические receipts не переписывались. Сырые логи, временные скрипты, UI-копии и результаты остались локально либо во внешнем хранилище; локальные ссылки в старых документах не гарантируются в новом clone.
