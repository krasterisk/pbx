## Spacing Scale

Кратные 4, набор идентичен `16-UI-SPEC.md` / 08 / 09 / 12 / 14 / 15:

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Зазор иконка↔текст в бейджах, подпись плитки, gap строки участника |
| sm | 8px | Gap плиток сетки; gap кнопок панели; gap полей формы; gap строк списка |
| md | 16px | Padding плитки, панели участников, мини-панели, тела формы; horizontal padding гостевого хедера |
| lg | 24px | Вертикальный зазор блоков списка; padding пустых состояний и pre-join Card |
| xl | 32px | Зазор крупных секций вкладок формы |
| 2xl | 48px | Мин. высота пустого состояния до иконки |
| 3xl | 64px | Не используется |

Exceptions (кратно 4 либо унаследовано из отгруженного кода):

- **44px** — мин. touch-target icon-only: микрофон, камера, выход, запись, приглашение, строка участника, триггер мини-панели. WCAG 2.5.5. Прецедент `.chromeTrigger`.
- **48px** — CTA гостя «Присоединиться к конференции» (прецедент `.dialCallBtn`).
- **56px** — высота topbar `ModuleShell` и хедера `ConferenceGuestShell`. Не менять.
- **60px** — mobile bottom-nav. Sticky-элементы считают `bottom` от него + `env(safe-area-inset-bottom)`.
- **72px** — высота sticky-бара софтфона. Мини-бар конференции складывается **над** ним.
- **12px** — только density chrome/topbar и `gap="12"` в шапке списка. Не размножать внутри комнаты.
- **160px** — `--conf-tile-min-width` desktop. На `max-width: 640px` — **120px**.
- **320px** — ширина панели участников (`≥1024px`) и мини-панели `min(320px, calc(100vw - 32px))`.
- **1px** — границы плиток, панели, разделители. В светлой теме плитка/панель: `box-shadow: 0 1px 4px rgba(0,0,0,0.06)`.
- **2px** — обводка говорящего и полоса активной вкладки формы.

## Color

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `var(--color-background)` `#09090b` | Фон списка; **стейдж видео**; фон гостевого шелла |
| Secondary (30%) | `var(--color-card)` `#0a0a0f` + `var(--color-border)` `#27272a` | Плитка, панель участников, Card таблицы, модалка, мини-панель, pre-join Card, хедер гостя |
| Accent (10%) | `var(--color-primary)` `#6366f1` | Только элементы из списка резервации ниже |
| Destructive | `var(--color-destructive)` `#ef4444` | Выйти / Завершить / Исключить / удалить комнату / отозвать ссылку / индикатор записи / баннеры ошибок |
| Warning | `var(--color-warning)` `#f59e0b` | «Ждём организатора», лобби, «Слабое соединение», «Видео не подключилось», «Переподключаемся» |
| Success | `var(--color-success)` `#22c55e` | Обводка говорящего 2px + glow; точка «вы в конференции»; «Ссылка скопирована» |
| Info | `var(--color-info)` `#3b82f6` | Счётчик участников, бейдж «Участник», бейдж «Телефон». Никогда не CTA |

Accent **зарезервирован** для: CTA «Создать комнату»; submit «Сохранить комнату» (edit/copy);
CTA «Войти в конференцию»; CTA «Присоединиться к конференции»; focus-ring (`--color-ring`);
открытое состояние триггера мини-панели; полоса активной вкладки формы;
`iconBadge` шапки `/conferences`; выбранная комната в `Select` шага маршрута.

Accent **не** протекает в: плитки в покое, бейджи ролей, строку D-20, иконки панели в покое,
строки истории, «Скопировать ссылку».

Говорящий — `success`, не `primary`: обводка меняется несколько раз в секунду и не должна
читаться как focus рядом с «Пригласить».

**Светлая тема.** Стейдж видео остаётся тёмным всегда (локальный тёмный контекст на корне
комнаты). Список, форма, история темы не форсируют. Гостевой шелл — `--color-background`,
без wallboard `color-scheme: dark` на весь экран.

## Copywriting Contract

Все строки через `t()` в `shared/config/locales/ru.ts` **и** `en.ts`. Namespace `conferences.*`
плюс `nav.conferences`. `hub.*` не трогать.

Жёсткие правила (из `16-UI-SPEC.md`, без смягчения):

- Длинное тире запрещено. Только `-` или запятая.
- Слово **Asterisk** запрещено. Система называется **Krasterisk**.
- D-36 / D-06: `conf{номер}_{uid}`, имена каналов, `sip_id`, `gst*`, `uniqueid` не показываются никому.
- D-20 дословно: `Максимальное число участников: {{count}}`. «Сейчас доступно», «Нагрузка сервера», «потоков», «кбит/с» запрещены.
- Эмодзи запрещены.
- Сырой API `message` не рендерится (16.1-UI-SPEC). Маппинг только по `code`.
- Кнопки диалогов и форм называют **объект**, не операцию. `common.cancel` / `common.save` на поверхностях фазы запрещены.
- Порядок футера: слева outline «оставить / не делать», справа submit или destructive. Менять только текст.

## Interaction and motion

- **Optimistic toggles (MUST):** любой сразу пишущий `Switch` — `onQueryStarted` → `updateQueryData` → `undo()` + toast.
- **Живые действия модератора:** оптимистичный патч участников, кнопка disabled на полёт, rollback + `toast.error`.
- **SSE** патчит тот же cache entry, что GET (прецедент `useCallCenterSSE`).
- **Запись** — не optimistic toggle: disabled + `Loader2` до ответа, затем бейдж `Идёт запись`.
- **Приглашение:** кнопка disabled + тост `live.inviteSent`; 403 → `live.inviteExternalForbidden`; fail → `live.inviteFailed`.
- **Отзыв:** confirm disabled, пока sync Kick+destroy не вернулись; тост `links.revoked` только после успеха.
- **R-RENEG:** 3–5 с без `video.videoWidth > 0` → `session.invite()` ≤2 раза → плитка `Avatar` + `live.videoFailed` + `live.videoRetry`. Остальные плитки не размонтировать.
- **Анимации** — только CSS `@keyframes` в SCSS. `motion.div` в `features/` / `pages/` / `widgets/` запрещён. Каждая пульсация (говорящий, reconnect, запись, ringing-триггер) имеет `@media (prefers-reduced-motion: reduce) { animation: none; }`.
- **Фокус:** `focus:ring-inset` на всех новых контролах.
- **Клавиатура:** иконочные кнопки — `title` + `aria-label` из ключей таблицы. `aria-expanded` / `aria-controls` на toggle панели участников. Горячих клавиш фаза не вводит (`Ctrl/Cmd+K`, `Ctrl/Meta+Shift+J` заняты).
- **pagehide** → `session.bye()`.
- Телеметрия ~5 с: `qualityLimitationReason` / `packetsLost` / `totalFreezesDuration`. Баннер `live.weakLink` при `cpu` | `bandwidth`. Мусорный payload сервер отбрасывает молча.
